## 最新變更

如果您覺得這款應用程式有用，別忘了給它評分：
[應用程式商店清單](https://github.com/lyskouski/app-finance/blob/main/README.md).

_完整的更新清單可透過「關於」導覽項目中的「提示」按鈕查看。_

### 8.5.0
- 新增 Teller (US)：使用您自己的 Teller 應用程式（基於憑證）匯入美國銀行與發卡機構的餘額及交易
- 新增 Investec Programmable Banking（南非）：使用您自己的 API 金鑰匯入 Private Banking 帳戶的餘額及交易
- 新增 Monzo Developer API（英國）：使用您自己的 OAuth 用戶端（在 Monzo 應用程式中核准）匯入餘額及交易
- 新增 Starling Bank Personal Access（英國）：使用個人存取權杖匯入餘額及交易
- 新增 Akahu Personal App（紐西蘭）：匯入已連結至 Akahu 的紐西蘭銀行的餘額及交易
- 新增 Up Banking API（澳洲）：匯入支出帳戶與儲蓄帳戶的餘額及交易，帳戶之間的轉帳作為轉帳
- 新增 Wise API (Global)：Wise 多幣別帳戶的餘額及交易匯入，換匯作為轉帳
- 新增 PrivatBank Autoclient（烏克蘭）：依 IBAN 匯入企業帳戶的餘額和交易
- 新增 monobank Personal API（烏克蘭）：金融卡和存錢筒的餘額及交易匯入，建立連結帳戶
- 新增 通知解析器 (Android)：根據銀行與支付應用程式的通知建立交易，自動辨識或透過自訂模式辨識
- 為檔案中沒有類別的匯入帳單預測預算類別

### 8.0.0
- 新增可展開區段的「整合」頁面
- 新增 Financial Transaction Services (FinTS 4.1)：德國銀行的帳戶、餘額及交易匯入
- 新增 SimpleFIN Bridge (US)：美國銀行與發卡機構的帳戶、餘額及交易匯入
- 新增 Enable Banking (EU)：歐洲銀行的帳戶、餘額及交易匯入（PSD2）

- 修正了換算匯率的精度
