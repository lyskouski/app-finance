## Latest Changes

_The full list of updates can be viewed via the "About" navigation item on the "Hints" button._

### 8.1.0
- Adding Teller (US): balances and import of transactions from US banks and card issuers with your own Teller application (certificate-based)
- Adding Investec Programmable Banking (South Africa): balances and import of transactions of Private Banking accounts with your own API keys
- Adding Monzo Developer API (United Kingdom): balances and import of transactions with your own OAuth client, approved in the Monzo app
- Adding Wise API (Global): balances and import of transactions of Wise multi-currency accounts, conversions as transfers
- Adding PrivatBank Autoclient (Ukraine): balances and import of transactions of business accounts by IBAN
- Adding Monobank Personal API (Ukraine): balances and import of transactions of cards and jars, creation of linked accounts
- Adding Notifications Parser (Android): transactions from notifications of banking and payment apps, recognized automatically or by a custom pattern
- Predicting Budget Category for imported Bills without a category in the file

### 8.0.0
- Introducing the Integrations page with expandable sections
- Adding Financial Transaction Services (FinTS 4.1): accounts, balances, and import of transactions from German banks
- Adding SimpleFIN Bridge (US): accounts, balances, and import of transactions from US banks and card issuers
- Adding Enable Banking (EU): accounts, balances, and import of transactions from European banks (PSD2)
- Adding import of bank statement files (`MT940`, `camt.053`), e.g. exported by Polish banks
- Fixing conversion rate precision
